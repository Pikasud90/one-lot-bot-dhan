# US-120: a cheat sheet in every tab

What the owner asked, on 25 Nov 2026: "add some detailed cheat sheet in each of the tabs", and
say how far each tab can be relied on in the real world, whether its data is accurate, and how
the volume and the machine learning confidence should be read in a live market.

What was built. Each of the nine tabs (Home, Live Desk, Volume, Simulator, Backtest Lab,
Data, News, ML Lab, Settings) now opens with a closed "cheat sheet" block. It has five parts:
what the tab is, how to read each figure, how to use it before, during and after the session,
how far to trust it, and what not to do with it. The trust part tags each line as real
(measured or recorded), estimate (from a model or a rule) or gap (untested or missing).

Where the content lives. The text is in src/onelot/ui/cheats.js, between the lines
"// CHEATS-DATA-BEGIN" and "// CHEATS-DATA-END", as one object keyed by tab. To change a
sheet, edit its entries there: keep short sentences, no dashes, and the tags real, estimate
or gap. The block code is cheatMount in the same file. The styles are the .cheat rules at the
end of src/onelot/ui/styles.css. The block sits first in each section of index.html.

Honesty rules the text follows. The desk only alerts and keeps paper trades. No study has
shown a tradable edge (docs/SETUP_BOOK.md). The sheets say how to read a number, never what to
buy or sell.

Tests. tests/test_us120_cheat_sheets.py checks the page structure and script order, the data
shape and tab order, sentence length and dashes, the part headings and tags, escaping, the
missing key case, cheatMount run in node, the CSS rules and node --check.

Source of the facts. The content was written from the code at commit fe14a03. When a tab
changes (a label, a threshold, a data source), re-read its sheet and fix it.
