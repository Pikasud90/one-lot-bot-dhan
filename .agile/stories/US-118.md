# US-118 — The Backtest Lab prices an option from real traded prices where the store has them

## Story
As the owner, I want a Lab option run to use the real traded price of the contract where it is stored, so that a backtest result is not about one point of premium a trade too good

## Acceptance criteria
- AC1: Given a NIFTY or BANKNIFTY monthly option run inside Nov 2021 to Nov 2026, when the Lab prices an entry or exit minute that the option store holds, then it uses that traded price and counts it as real
- AC2: Given a minute or an index the store does not hold, when the Lab prices it, then it uses the model as today and counts it as modelled
- AC3: Given a finished run, when its result is shown, then it says what share of its fills were real prices and what share modelled
- AC4: Given the same run with real prices switched off, when it is repeated, then the result equals the result of the Lab today
