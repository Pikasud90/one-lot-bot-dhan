# US-126 — The market pulse uses the monthly expiry for its put call ratio and stores no made-up confidence

## Story
As the owner, I want the pulse to read the same contract month the desk trades, so that a near-expiry day does not distort it

## Acceptance criteria
- AC1: Given the put call ratio part of the pulse, when it picks an expiry, then it uses the expiry the desk option alerts use and not the first one of the broker list
- AC2: Given a pulse row, when it is stored, then its confidence is empty instead of the fixed 0.5
- AC3: Given the News tab, when a score is shown, then no confidence is shown for a pulse row
