# US-008 — Reproducible build and CI

## Story
As the owner, I want exact dependency pins and an automatic gate on every push, so that the product behaves the same on any machine and regressions are caught before they ship.

## Acceptance criteria
- AC1: Given a clean checkout, when the documented install command runs, then it installs exactly the pinned versions from a lock file (hashes where available) and the app starts.
- AC2: Given a push or pull request, then a CI workflow runs ruff format check, ruff check, the mypy ratchet, the full tests, domain lint and the quality gate, and fails on any regression.
- AC3: Given the suite, then its wall time is under 60 seconds (slow tests are marked and run nightly) without lowering what is tested.
- AC4: Given a CHANGELOG, then every release entry follows Keep a Changelog headings and the version in pyproject matches the git tag.
