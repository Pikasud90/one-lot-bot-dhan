# US-007 — Observability: metrics, health and a system status panel

## Story
As the owner, I want to see whether every part of the system is healthy and fast, so that a silent failure is visible within a minute.

## Acceptance criteria
- AC1: Given GET /api/metrics, then it exposes in Prometheus text format: desk poll duration, bars lag per instrument, alerts per strategy, paper open trades, Telegram queue depth and latency, Dhan request counts by status and rate-limit headroom.
- AC2: Given a System panel in the app, then it shows the same indicators with red/amber/green thresholds and the last error for each subsystem.
- AC3: Given logs, then they are structured JSON lines with a correlation id per alert, rotated, and contain no secrets.
