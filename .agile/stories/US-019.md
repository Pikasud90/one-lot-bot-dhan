# US-019 — Resumable five-year Dhan backfill

## Story
As the owner, I want a one-click, resumable download of five years of 1-minute and daily bars for the watchlist and India VIX, so that backtests and the promotion gate run on real history.

## Acceptance criteria
- AC1: Given the Data API is active, when the backfill runs, then it fetches in 85-day windows within the Dhan limits, persists after every window and can be stopped and resumed without re-downloading finished windows.
- AC2: Given a rate-limit or token-expiry error mid-run, then it backs off or pauses with a clear status and resumes after the token is renewed.
- AC3: Given the finished corpus, then a quality report lists per series: first and last bar, session count, gap count, zero-volume bars and suspected corporate-action jumps, and the Data tab shows it.
