# US-124 — The Lab can cost a stock run as a delivery trade held for days

## Story
As the owner, I want a stock backtest costed the way my stock trades are, so that the Lab does not judge a delivery rule with intraday charges

## Acceptance criteria
- AC1: Given a stock run marked delivery, when its costs are computed, then they come from the delivery cost model the desk uses (src/onelot/delivery/money.py) with the depository charge on the sale
- AC2: Given the same run marked intraday, when it is repeated, then the result equals the result of the Lab today
- AC3: Given a delivery run, when its result is shown, then the page says delivery costs were used
