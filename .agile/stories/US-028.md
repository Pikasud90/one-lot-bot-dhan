# US-028 — Fix: alerts served by the Yahoo fallback are labelled live

## Story
As the owner, I want an alert built on delayed Yahoo bars to say so, so that I never trade a 15-minute-old price believing it is live.

## Acceptance criteria
- AC1: Given a Dhan primary source and an instrument for which Dhan returned no bars so Yahoo served it (served_by is yahoo), when the desk raises an alert, then data.delayed is True and data.delay_note says Yahoo bars run about 15 minutes behind; given Dhan served it, data.delayed is False; the Desk header badge and the Telegram tag use the same rule.

## Non-functional requirements
**2026-11-01T13:57+05:30**
- One-line fix in Desk._raise_signal: delayed = src startswith yahoo (not self.source.delayed). Regression test through the tests/desk harness with a CompositeBars whose primary returns an empty frame for one series.
