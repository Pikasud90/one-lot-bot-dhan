## The state of a session (fixed in advance; do not tune)
For session t with daily bars (open, high, low, close), all inputs known at the close of t:
- r = ln(close_t / close_t-1); s = the standard deviation of r over the 20 sessions before t;
  z = r / s.
- Direction: `bull` when z > +0.5, `bear` when z < -0.5, else `flat`.
- rng = (high_t - low_t) / close_t-1; m = the median of rng over the 20 sessions before t.
  Size: `active` when rng > m, else `calm`.
- The first 21 sessions have no state. A session's state is (direction, size).

## The model (plain counting, with honest uncertainty)
- Base rates of bull / flat / bear and of calm / active over the instrument's history.
- First order: counts of (yesterday's direction -> today's direction). Second order: counts
  of (the last two directions -> today's direction). Size: first order (calm/active).
- Probability of tomorrow's direction given a context with counts n_b and total n:
  p_b = (n_b + 10 x base_b) / (n + 10) (pulled toward the base rate when n is small).
- Which context is shown: the last two sessions when that context has n >= 60, otherwise the
  last session. The page shows both rows with their counts.
- Runs: for bull and for bear, after a run of exactly 1, exactly 2, and 3 or more sessions
  of that direction: the share that continued, with n (the owner's own example).
- Lean = the most likely direction. Edge = its probability minus its base rate, in points.
  z = edge / sqrt(base x (1 - base) / n). Conviction: `none` when |z| < 1; `weak` 1 to 2;
  `moderate` 2 to 3; `strong` 3 or more AND edge of 5 points or more. Score 0 to 100 =
  min(100, round(25 x |z|)). The same for size (calm/active).
- Walk-forward check per instrument: from the 250th stated session on, estimate on the
  sessions before t only, name the most likely direction for t; report n, the hit rate, the
  hit rate of always naming the most common direction so far, and the same pair for size.
