# US-113: Real put prices for FINNIFTY, MIDCPNIFTY and SENSEX and for weekly contracts

## Story
As the owner, I want real option prices of the other three indices and of weekly contracts in the
data store, so that an option study on them is judged on real prices and not on estimates.

## Acceptance criteria
- AC1: Given scripts/real_puts_fetch.py with --series FINNIFTY,MIDCPNIFTY,SENSEX (default stays
  NIFTY,BANKNIFTY), when the plan stage runs, then the ledger holds the needs of each series and no
  request is sent.
- AC2: Given a flag option (MONTH or WEEK), when planned, then each need carries the flag and the
  store key holds it (RollingKey.flag), so a weekly and a monthly block of the same day never meet.
- AC3: Given the fetch stage, then it sends at most one request a second, only after 15:40 IST and
  before 21:15, stops after three refusals in a row, and never asks for a day already held (here or
  in the app's store).
- AC4: Given the three probe requests, then each new series is compared bar by bar with a day the
  store already holds, and a mismatch stops the fetch.
- AC5: Given scripts/merge_option_bars.py --dry-run, then it prints the blocks that would be added
  per underlying and flag, and replaces nothing; the real merge adds only missing blocks.
- AC6: Given the status stage, then it prints the needs left per tier, series and flag.

## Non-functional requirements
- Only the data is added; no study, no verdict, no alert changes in this story.
- Dhan's plan is shared with the desk: no request before 15:40 IST, one a second.
- The owner approves the merge into `data/expired_options.db` (a backup is made first, as on 25
  Nov).

## Public contract
- `scripts/real_puts_fetch.py`: `SERIES = ("NIFTY", "BANKNIFTY")` (line 62) and `PROBES` (line 77)
  are fixed; the stages `probe`, `plan`, `fetch`, `status`; `Ledger`.
- `onelot.data.expired_options`: `RollingKey(underlying, code, opt, rel, flag="MONTH")` (line 86),
  `OptionBarStore`, `fetch_days`.
- `scripts/merge_option_bars.py`: key `(underlying, flag, code, opt, rel, day)`; `--from`, `--into`,
  `--dry-run`.
- Tests: `tests/test_real_puts_fetch.py`, `tests/test_merge_option_bars.py` (extend, no network).
