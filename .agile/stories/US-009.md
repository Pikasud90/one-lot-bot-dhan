# US-009 — Schema migrations and backups

## Story
As the owner, I want versioned schema changes and automatic backups, so that an upgrade or a disk problem cannot lose my paper ledger or journal.

## Acceptance criteria
- AC1: Given an existing database from the prototype, when the app starts after this change, then it migrates to the baseline version without data loss and records the version.
- AC2: Given a nightly backup job, then a consistent SQLite online backup is written with 14-day retention and a restore test proves the backup opens and passes an integrity check.
- AC3: Given a failed migration, then the app refuses to start and says how to restore the pre-migration backup taken automatically.
