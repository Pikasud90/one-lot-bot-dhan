# US-020 — Matrix sweep at scale with pre-registered gate

## Story
As the owner, I want the full strategy by instrument by timeframe by setting sweep to run unattended on five years of data and report only what survives out-of-sample, so that I can see whether any real alpha exists.

## Acceptance criteria
- AC1: Given the 2520-run preset matrix, when it runs on the real corpus, then it completes unattended, is resumable, reports progress and an ETA, and uses available cores.
- AC2: Given the pre-registered thresholds, then each cell is classified PASS, WATCH or FAIL only from out-of-sample walk-forward trades with costs doubled and slippage doubled stress, and the report lists the multiple-testing count so the owner can see how many cells were tried.
- AC3: Given no cell passes, then the report says so plainly and recommends new strategies rather than loosening any threshold.
